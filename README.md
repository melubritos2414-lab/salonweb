SalonWeb – Gestión de Citas y Servicios
Aplicación web desarrollada en PHP y MySQL para la gestión de citas, clientes y servicios de un salón de belleza.
Incluye autenticación, registro de datos, panel de administración y operaciones CRUD completas.
